## 使用流程

1. 对照流量、周期与设备数选择套餐，确认购买页的最终价格。
2. 购买后按服务页面给出的订阅与客户端指引完成配置。
3. 遇到导入或连接问题，通过购买页的在线客服咨询。

## 注意事项

- 各档流量与设备数差异较大，应以同时在线的设备数作为筛选起点。
- 流媒体平台与播放效果受节点、当地网络及服务方规则影响。
- 优惠券与实际结算金额以购买页显示为准。
